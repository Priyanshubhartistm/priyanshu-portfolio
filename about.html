A bit about how I work

The story, the stack, and the way I like to build software.

I'm Priyanshu Bharti, a Full-Stack Developer from Bihar, India, currently studying at Dr. C.V. Raman University, Vaishali. I like working across the whole stack — from database schema to pixel-perfect UI — but the last few months have pulled me deep into Bitcoin and the Nostr protocol: I'm a Software Engineer on Nostream, a production-grade Nostr relay, and a Dev Fellow at Bitshala, a Bitcoin developer-education community. That path started with Summer of Bitcoin, a global internship that matched me with mentors to ship real fixes into open source Bitcoin infrastructure.

Day to day I reach for JavaScript and TypeScript, with React on the frontend and Node.js/Express on the backend, MongoDB or PostgreSQL depending on the shape of the data, and Python for scripting and quick tooling. I've also picked up Go recently building Agent Guardrail, a safety layer that intercepts and evaluates every tool call an AI agent tries to make before it executes. Docker keeps environments predictable, and Git is home base for everything.

Open source is a big part of how I learn — I've opened 130+ pull requests across GitHub, with the most going into KubeEdge (a CNCF Kubernetes-native edge computing project), Palisadoes Foundation's Talawa, Flatcar Container Linux, and ContextVM. I also spend time on community building — I've been a Microsoft Learn Student Ambassador, a Google Cloud Arcade Facilitator, and a campus ambassador for Unstop, LetsUpgrade, Postman, MyGov India and takeUforward — and volunteered teaching at a government school back home.

Currently open to full-stack and backend roles, especially anywhere Bitcoin, Nostr or developer tooling intersect with real infrastructure work. If any of this resonates, get in touch.
